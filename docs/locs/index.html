Loc Style Finder

38 men's loc styles, scored on 15 attributes

Every style is reduced to the same 15 attributes (thickness, length, how the sides are cut, how tidy the roots are, how it is worn, colour, upkeep and so on). Similarity is computed from those attributes only, never from a photo or the person wearing it. Open a style to see the closest matches and the furthest contrasts.

How similarity is scored

Each style is a point in a 15-attribute space. Distance between two styles is a weighted average of per-attribute differences: numeric attributes contribute how far apart they are on their scale, categorical ones contribute 0 (same) or 1 (different). Similarity is 1 minus that distance. Heavier weights go to the attributes a barber or loctician would name first: thickness, length and how the sides are cut.
